# 🛒 Amazon UI Sample Page

This is my **first HTML & CSS project**, created as a practice project to understand the basics of frontend web development.

This project is a **static Amazon-inspired sample page** built using only HTML and CSS. It focuses on recreating the visual layout and design of an e-commerce homepage.

## 🛠️ Technologies Used

- HTML
- CSS

## ✨ Project Highlights

- Amazon-inspired UI design
- Navigation bar
- Hero banner section
- Shop/product sections
- Product images and titles
- Footer section
- Static layout for practice

## ⚠️ Note

This is **only a sample/static UI page** created for learning purposes.

- No buttons or links are functional
- No JavaScript is used
- No backend is connected
- No actual shopping functionality
- The page is created using only HTML and CSS

## 🎯 Purpose

The purpose of this project was to practice:

- HTML page structure
- CSS styling
- Flexbox and layout
- Images and sections
- Creating a real-world website UI
